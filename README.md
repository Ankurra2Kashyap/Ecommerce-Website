# CartCraft

**CartCraft** is a fully functional e-commerce platform designed to provide seamless product browsing, cart management, and secure payment processing. The platform is built with modern technologies to ensure a scalable and user-friendly experience.

## Features

- **Product Browsing**: Users can explore a catalog of products with detailed descriptions and pricing.
- **Cart Management**: Add, update, or remove items from the shopping cart with a smooth and intuitive interface.
- **Authentication**: Secure user authentication with session management for login, registration, and profile access.
- **Order Management**: Track and manage user orders, ensuring a complete e-commerce experience.
- **Secure Payments**: Integrated with Stripe API for safe and reliable payment processing.

## Tech Stack

- **Frontend**: ReactJS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Payment Gateway**: Stripe API
